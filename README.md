# finally-edit-nnl-project
اصلاحيه نهايي پروژه شبكه عصبي دانشگاه خواجه نصير (a.m.f)
این پروژه یک شبکه عصبی کانولوشنی (CNN)  برای تشخیص اعداد دست‌نویس از مجموعه داده MNIST پیاده‌سازی شده است . در اين پروژه یک تصویر دست‌نویس از مسیر مشخص‌شده توسط کاربر پردازش شده و عدد آن را تشخیص می‌دهد.در حال حاضر خود يك آدرس پيش فرض به آن داده ام ميتواند آدرس مد نظر خود را در آن جايگذاري كنيد .

مجموعه داده MNIST شامل ۶۰,۰۰۰ تصویر آموزشی و ۱۰,۰۰۰ تصویر تست است.
این تصاویر ۲۸×۲۸ پیکسلی و سیاه‌وسفید هستند
برای بهینه‌سازی وزن‌ها از  مدل Adam Optimizer استفاده می‌شود.
تابع Cross-Entropy Loss به مدل کمک می‌کند که تفاوت پیش‌بینی‌ها را کاهش دهد.
مدل به مدت ۵ Epoch آموزش داده می‌شود
